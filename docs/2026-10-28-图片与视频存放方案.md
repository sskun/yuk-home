# 图片与视频存放方案

## 结论

| 类型 | 规模预估 | 放哪里 | 原因 |
| --- | --- | --- | --- |
| 图片 | 2 年内约 500 张 | 本仓库 `src/assets/` | 构建期自动转 WebP、多尺寸；500 张远低于 Pages 免费版 2 万文件上限 |
| 视频 | 约 50 条 | Cloudflare R2（或 B 站 / YouTube 外链） | 单个文件超过 25 MiB 就无法部署到 Pages；视频放进 git 会让仓库无限膨胀 |

## 图片：放在仓库里

### 目录

```
src/assets/
├─ avatar/      头像
├─ projects/    项目 logo、产品截图
├─ articles/    文章配图（按文章 slug 建子目录，如 articles/agent-architecture/）
└─ gallery/     其他展示图
public/         只放必须保持固定网址的文件：favicon、og 分享图
```

### 怎么用

- **配置文件里**（`site.config.ts`）直接写路径字符串：`'/src/assets/projects/xxx.png'`。
  组件统一走 `components/ui/SmartImage.astro`，构建时自动转 WebP、生成 srcset、带宽高（不产生布局抖动）。路径写错会直接构建失败并提示文件名。
- **Markdown 文章里**用相对路径：`![说明](../../assets/articles/xxx/fig1.png)`，Astro 同样会自动优化。

### 入库前

- 原图长边不超过 2400px，单张控制在 1 MB 以内（截图用 PNG，照片用 JPG）。仓库存的是原图，网页上用的是构建产物，所以原图不必压到很小，但也别放相机直出的 10 MB 大图：git 会永久保留每个版本。
- 截图注意隐私：路径、账号、真实数据。

### 容量估算

500 张 × 平均 500 KB ≈ 250 MB 原图进入仓库，可以接受。每张图生成约 3 个尺寸，产物约 1500 个文件，远低于 2 万上限。
构建时间会随图片数增加（sharp 处理约 0.1～0.3 秒/张/尺寸），500 张大约多 2～5 分钟。如果以后觉得慢，再考虑 Cloudflare Images。

## 视频：放在 R2

### 为什么不放仓库

- Cloudflare Pages 单文件上限 **25 MiB**，一条 1080p 视频通常就超了。
- GitHub 单文件超过 100 MB 直接拒绝推送；即使用 Git LFS，也有额度和 Pages 构建兼容问题。
- 视频改一版，旧版本永远留在 git 历史里。

### 推荐做法

1. 开通 R2，建一个桶（如 `yuk-media`），绑定自定义子域名（如 `media.你的域名`）。R2 免费 10 GB 存储，下载流量不收费：50 条 × 50 MB ≈ 2.5 GB，在免费额度内。
2. 视频转码后上传：H.264 MP4，1080p 码率 4～6 Mbps，并导出一张封面图（封面放 `src/assets/`）。
3. 在配置里引用：首屏 `stage.video: { src: 'https://media.你的域名/xxx.mp4', poster: ... }`。
4. 修改 `public/_headers` 的 CSP，加上 `media-src 'self' https://media.你的域名`，否则浏览器会拦截视频。

### 备选

- **B 站 / YouTube 外链**：零成本，还能带来平台流量，适合教程、演示类长视频。需要在 CSP 里放开对应的 `frame-src`。
- **Cloudflare Stream**：自动转码和自适应码率，但按分钟收费，个人站暂时用不上。
