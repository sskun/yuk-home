## 为什么要记

同时用好几款 AI 编程工具之后，最常见的问题不是「它能不能做」，而是「上次它是怎么做对的」。

## 怎么切分

按天切分会话，再按工具来源打标签。一条记录只保留时间、工具、提示和结果摘要。

```ts
const day = (t: Date) => t.toISOString().slice(0, 10);
```

## 为什么先用 BM25

几千条以内的语料，BM25 召回快、结果可解释，调参也简单。向量检索留到语料再大一个量级时再说。
